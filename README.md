# ITSM-Ticketing-Tool--Frontend

A web-based ITSM Ticketing Tool interface created as a personal web development project. This project focuses on practicing and improving frontend development skills using HTML, CSS, and JavaScript.

 

# About the Project

This project is a non-functional frontend application intended primarily for practicing web development skills. It was created to explore webpage structuring, styling, responsive layouts, and basic JavaScript interactions.

The application includes a dashboard and separate pages for creating, viewing, searching, updating, and deleting IT support tickets.

Please note that the current version uses sample ticket information and does not have a fully implemented ticket management system. Features such as actual ticket creation, database storage, searching, updating, and deletion are not yet functional.

 

# Main Features

Dashboard – Displays sample ticket statistics, including total, open, in-progress, and resolved tickets.
Create Ticket – Provides a sample form layout for entering IT support requests.
View Ticket – Displays sample ticket information and details.
Search Ticket – Provides a search interface using a ticket number.
Update Ticket – Displays an interface for viewing and editing ticket details.
Delete Ticket – Provides an interface for searching and deleting ticket records.
Generate Ticket Summary – Presents sample ticket statistics and recent tickets.
Light/Dark Mode – Allows users to switch between light and dark themes.
Responsive Layout – Adjusts the interface for mobile phones, tablets, and desktop screens.
 
# Built With

The following technologies and resources were used to develop this project:

HTML5 – For the structure of the web pages.
CSS3 – For styling, layouts, and responsive design.
JavaScript – For basic interactive features.
Font Awesome – For icons used throughout the application.
Google Fonts – Roboto and Montserrat.
